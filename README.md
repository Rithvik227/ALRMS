# ALRMS
The Automated Linear Rail Movement System, or ALRMS, aims to use Arduino Uno Rev3, A Wantai NEMA 17 stepper motor, and other corresponding components to create an interactive movement for a dolley sliding on pre-built rails in an actobotics kit. The system is capable of performing automated &amp; randomized, smooth &amp; linear, or user controlled movement.

Schematics, code, and CAD designs are all available to use, build off of, or edit. There will be no updates as the rail is being modified and updated by other students. This version of the rail was deployed in May 2026.
